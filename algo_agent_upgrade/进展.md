## 真实 API 结果

### Agent Live：全量工具 vs Hybrid Top-2 + Abstention

数据集：`agent-live24.v2`，24 条，DeepSeek-v4-flash。

| 指标 | 全量工具 | 路由后 | 变化 |
|---|---:|---:|---:|
| Strict TSR | 0.833 | 0.875 | +4.17pp |
| Tool Precision | 0.400 | 0.917 | +51.67pp |
| Tool Recall | 1.000 | 1.000 | 持平 |
| 冗余调用率 | 0.600 | 0.083 | -86.1% |
| Prompt Tokens | 44177 | 25991 | -41.2% |
| Tokens/Success | 1739.7 | 1305.8 | -24.9% |
| P95 | 11.64s | 5.59s | -52.0% |

失败演进保留：

1. 初版 Hybrid Top-3 缺少 `lookup` 中文别名，Recall 只有 `0.864`、TSR `0.750`。
2. 补别名但不允许 abstain 的 Top-2，Recall 恢复 `1.0`，但 Precision 仅 `0.431`。
3. 增加无工具 abstention 后，Precision 达 `0.917`，Recall 保持 `1.0`。

边界：当前 A/B 每个配置只跑一轮，不把 P95 差异宣称为稳定置信区间。

### RAG 学习融合与校准

`rag96.v2` 按语义簇做确定性 60/20/20 切分：train/dev/test=`40/12/12` Query。

| Test 指标 | BGE 排序基线 | 线性融合 | 变化 |
|---|---:|---:|---:|
| Recall@5 | 0.958 | 0.958 | 持平 |
| MRR | 0.764 | 1.000 | +23.61pp |
| nDCG@5 | 0.773 | 0.948 | +17.45pp |

- 候选级 Brier：`0.070`
- 候选级 ECE：`0.046`
- ACL candidate touch / exposure：`0 / 0`

首轮错误统计口径（仅 4 条 test、候选概率误作 Query 概率）保留在
`RAG_FUSION_CALIBRATION_V1.json`；修正结果为 V2，不覆盖失败证据。

### RAG 分区检索与 HNSW

- L1/L2/L3 全链路 ACL candidate touch 和 exposure 均为 `0`。
- HNSW L3：TSR `0.979`、nDCG@5 `0.893`、RAG P95 `662ms`。
- 当前小语料上 HNSW 对 partitioned 精确路径没有稳定延迟优势，不写“显著加速”。
- HNSW 的有效亮点是正式入口缓存复用、增量 revision 刷新和 Recall-Latency 可调能力。
